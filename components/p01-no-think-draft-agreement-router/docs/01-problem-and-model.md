# P01 · 01-problem-and-model

> 属于 [P01 no-think-draft-agreement-router](../README.md) 的文档分册。


## 问题：它到底在解决什么

### 真实场景

一个日请求 10 万次的分类型服务：用户贴一段文本，要求归到 40 个类别之一。其中约七成是「一看就知道」的样本（关键词明确、句式标准），另外三成需要真正读进去、比对规则、处理歧义。如果每条请求都开深度思考，等于让七成简单样本陪着三成难题一起付思考费。真实账单长这样：思考 token 平均每条 1,800，其中七成请求贡献的思考是纯浪费；延迟从 0.8 秒涨到 5–6 秒，用户在前 2 秒就关掉页面。

### 朴素做法为何失败

第一反应是按「长度」或「关键词」判断难度：短问题=简单，长问题=难，出现「分析」「推理」「为什么」就升级。这条启发式在真实流量上判别力接近随机，原因是难度与长度几乎不相关：「证明根号 2 是无理数」只有 11 个字，是硬题；贴进来 3,000 行日志问「哪一行报错」，是最简单的模式匹配。第二反应是让模型自评：「请给出你对答案的置信度 0–100」。这条路更危险——自评置信度系统性偏高，且恰在分布外样本上最自信，等于在最需要升级的地方告诉你「不用升级」。

### 失败的代价

代价分三层，且只有第一层是显性的。第一层是账单：每条多烧约 1,800 思考 token，10 万条/天即 1.8 亿 token/天，按月计是六位数人民币量级的差异（具体数额取决于模型单价，此处只给量级，不报无源单价）。第二层是延迟：深度思考把 P95 延迟从 0.8 秒推到 5 秒以上，转化率与延迟的关系在业界是稳定的负相关，这一层损失通常比账单大一个量级。第三层最隐蔽：因为贵，团队会主动降低调用频次、缩小上下文、减少复核轮次——**成本压力会反向侵蚀质量**，而这条损失从不出现在任何报表里。



## 概念模型与术语

**草稿（draft）** — 一次不开启深度思考的完整作答。它必须能独立成为一个答案，而不是「思路提纲」——只有完整答案之间才有可比性。

**一致性（agreement）** — K 份草稿中，归于同一答案簇的最大占比（0–1）。它是**行为层面**的收敛度量，不是模型自陈的置信度。

**答案簇（answer cluster）** — 被归并规则视为同一个答案的一组草稿。「簇」的定义方式直接决定一致性的含义，这是本机制最容易被做错的地方。

**归并键（merge key）** — 把一份草稿映射到某个簇的函数。参考实现取「去空白后前 12 字符小写」，生产环境应换成语义等价判定。

**路由（route）** — 把一致性分数映射成 `skip_think` / `think` 的二值决策。二值是刻意的，见决策 2：多级路由会引入没人校准的中间档。

**跳思率（skip rate）** — 被判定为 `skip_think` 的请求占比。它是**运行期最重要的监控指标**，因为它一变就说明输入分布变了。

**假跳过（false skip）** — 本该深度思考却被判定为可跳过。这是唯一会伤正确率的错误方向。

**假升级（false escalate）** — 本该跳过却被送去深度思考。只浪费钱，不伤正确率——本机制的设计哲学是把风险尽量推向这一侧。

**草稿独立性（draft independence）** — 多份草稿是否真的独立采样。同 seed / 同上下文 / 同温度下重复调用得到的「一致」，测的是采样器的确定性，不是知识的稳定性。

**多数幻觉（majority hallucination）** — K 份草稿错得一模一样，一致性高达 1.00，机制判定「很确定，跳过」。实测见实验 3：四个都错的草稿 agreement 同样是 1.00。

### 概念之间的关系

```text
             ┌────────── 输入问题 ──────────┐
             │                              │
             ▼                              ▼
     [采样 K 份草稿]                   （无输入 → 返回 0.0 → 升级）
             │
             ▼
     [归并键 merge_key] ──► 答案簇 {c1, c2, ...}
             │
             ▼
     agreement = max|ci| / K      ← 唯一信号
             │
      ┌──────┴───────┐
      ▼              ▼
 a ≥ 阈值        a < 阈值
 skip_think       think
 （省钱省时）   （花算力买正确率）
      │              │
      └──────┬───────┘
             ▼
      记录 skip_rate（监控分布漂移）
```
